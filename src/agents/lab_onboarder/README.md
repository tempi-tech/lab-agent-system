# Lab Onboarder Agent

Discord新規メンバーのオンボーディングを支援するエージェント。シンプルな4フィールド入力でプロフィールカードを作成し、Forumに投稿します。

## 機能概要

| 機能 | 説明 |
|------|------|
| プロフィール作成 | 名前・紹介文・タイプ・Xリンクの4項目入力 |
| AI紹介文生成 | 紹介文が空欄の場合、タイプに基づいてLLMが自動生成 |
| Forum投稿 | `#profiles` フォーラムにスレッド自動作成・更新 |
| チャンネル推薦 | 日報データからタイプに合ったチャンネルを提案 |

## コマンド

| コマンド | 説明 |
|---------|------|
| `/onboard` | プロフィールカード作成モーダルを開く |
| `/profile_edit` | 既存プロフィールを編集 |

## 入力フィールド

| フィールド | 必須 | 説明 |
|-----------|------|------|
| 表示名 | ✓ | コミュニティでの表示名（Discord名がデフォルト） |
| コミュニティへの一言 | | 自己紹介文（空欄ならAIが生成） |
| タイプ | ✓ | 8タイプから1つ選択（下記参照） |
| Xリンク | | X（旧Twitter）プロフィールURL |

### タイプ（Archetype）

| タイプ | 説明 |
|--------|------|
| Builder | 作る人（開発、プロトタイプ） |
| Researcher | 調べる人（論文、分析） |
| Operator | 運用する人（自動化、ワークフロー） |
| Curator | まとめる人（ニュース、情報整理） |
| Connector | 繋げる人（コミュニティ、イベント） |
| Critic | 批評する人（レビュー、議論） |
| Creative | 創造する人（デザイン、アート） |
| Strategist | 戦略を立てる人（プロダクト、マーケット） |

## 環境変数

### 必須

| 変数名 | 説明 |
|--------|------|
| `GUILD_ID` または `LAB_ONBOARDER_GUILD_ID` | Discord サーバーID |
| `PROFILE_FORUM_CHANNEL_ID` | プロフィールフォーラムのチャンネルID |
| `GOOGLE_API_KEY` | Gemini APIキー（紹介文生成用） |

### オプション

| 変数名 | デフォルト | 説明 |
|--------|-----------|------|
| `LAB_ONBOARDER_LLM_MODEL` | `gemini-3-flash-preview` | 紹介文生成に使用するモデル |
| `LAB_ONBOARDER_SQLITE_PATH` | `data/lab_onboarder/profiles.sqlite` | SQLiteファイルパス |
| `LAB_ONBOARDER_LOG_PATH` | `data/lab_onboarder/lab_onboarder.log` | ログファイルパス |
| `LAB_ONBOARDER_LOG_CHANNEL_ID` | - | ログ送信先チャンネルID |
| `LAB_ONBOARDER_DEBUG` | `false` | デバッグモード |

### 権限設定

| 変数名 | 説明 |
|--------|------|
| `LAB_ONBOARDER_ALLOWED_ROLE_IDS` | コマンド使用可能なロールID（カンマ区切り） |
| `LAB_ONBOARDER_ADMIN_ROLE_IDS` | 管理者ロールID（デバッグコマンド用） |
| `LAB_ONBOARDER_DM_ALLOWLIST_USER_IDS` | DM許可ユーザーID（カンマ区切り） |
| `LAB_ONBOARDER_DM_ALLOWLIST_USERNAMES` | DM許可ユーザー名（カンマ区切り） |

## 出力ファイル

`data/lab_onboarder/` に以下が保存されます：

| ファイル | 説明 |
|----------|------|
| `profiles.sqlite` | プロフィールデータベース |
| `lab_onboarder.log` | 実行ログ |

### SQLite スキーマ

**profiles テーブル（主要カラム）**

| カラム | 型 | 説明 |
|--------|-----|------|
| `discord_user_id` | INTEGER (PK) | Discord ユーザーID |
| `display_name` | TEXT | 表示名 |
| `introduction` | TEXT | 紹介文 |
| `archetype` | TEXT | タイプ（8種類） |
| `x_profile_url` | TEXT | X プロフィールURL |
| `forum_thread_id` | INTEGER | Forumスレッド ID |
| `forum_message_id` | INTEGER | Forum投稿メッセージID |
| `created_at` | TEXT | 作成日時（ISO 8601 UTC） |
| `updated_at` | TEXT | 更新日時（ISO 8601 UTC） |

```
│ あります。気軽に話しかけてください！ │

```

## チャンネル推薦

プロフィール作成後、日報データを基にタイプに合ったチャンネルを自動推薦します。

- 過去14日間の日報からチャンネル情報を抽出
- タイプ別のキーワードでスコアリング
- 上位5チャンネルを推薦

## トラブルシューティング

### プロフィールが生成されない

**症状**: `/onboard` でエラーが出る

**考えられる原因**:
- `GOOGLE_API_KEY` が未設定
- 必須フィールド（表示名、タイプ）が未入力
- タイプの入力が8種類のいずれとも一致しない

**確認**:
```bash
# ログを確認
docker logs lab-agent --tail 50 | grep lab_onboarder
```

### 紹介文が自動生成されない

**症状**: 空欄にしてもAI生成されない

**原因**: Gemini API のエラー

**確認**:
- `GOOGLE_API_KEY` が正しく設定されているか
- Gemini API のクォータ・レートリミット

### チャンネル推薦が表示されない

**原因**: 過去14日間の日報データがない

**確認**:
```bash
# 日報データベースの存在確認
ls -la data/daily_reporter/digests.sqlite
```
